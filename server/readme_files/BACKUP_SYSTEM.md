# 翻译文件备份系统

## 📋 系统概述

翻译文件备份系统自动备份旧文件，使用正确的文件名存储新文件，并提供备份文件管理功能。

## 🔧 文件命名规则

### 新文件命名
- 使用配置文件中的 `lanFile` 字段作为文件名
- 例如：`en_US.json`、`ja_JP.json`、`zh_CN.json`

### 备份文件命名
- 格式：`{原文件名}_backup_{时间戳}.json`
- 例如：`en_US_backup_2024-01-15T10-30-45-123Z.json`

## 📁 目录结构

```
translations/
├── myStar/
│   ├── en_US.json              # 当前英文翻译文件
│   ├── ja_JP.json              # 当前日文翻译文件
│   ├── zh_CN.json              # 当前中文翻译文件
│   └── backups/                # 备份目录
│       ├── en_US_backup_2024-01-15T10-30-45-123Z.json
│       ├── en_US_backup_2024-01-14T15-20-30-456Z.json
│       └── ja_JP_backup_2024-01-13T09-15-20-789Z.json
└── PicsAi/
    ├── en_US.json
    ├── ja_JP.json
    └── backups/
        └── en_US_backup_2024-01-12T14-25-35-012Z.json
```

## 🚀 工作流程

### 1. 文件上传流程
1. 用户选择翻译文件
2. 选择App和语言
3. 系统检查目标文件是否存在
4. 如果存在，先备份到 `backups/` 目录
5. 使用正确文件名保存新文件

### 2. 备份触发条件
- 上传同名文件时自动备份
- 备份文件包含时间戳，避免冲突
- 备份文件按时间倒序排列

## 📡 API端点

### 获取翻译文件列表
**GET** `/translation_files/:app`

**响应格式**:
```json
[
  {
    "fileName": "en_US.json",
    "language": "英文",
    "size": 1024,
    "uploadTime": "2024-01-15T10:30:45.123Z",
    "backupCount": 3
  }
]
```

### 获取备份文件列表
**GET** `/translation_backups/:app/:filename`

**响应格式**:
```json
[
  {
    "fileName": "en_US_backup_2024-01-15T10-30-45-123Z.json",
    "size": 1024,
    "backupTime": "2024-01-15T10:30:45.123Z"
  }
]
```

### 下载备份文件
**GET** `/download_backup/:app/:filename`

## 🎯 前端功能

### 文件列表显示
- 显示当前文件名（如 `en_US.json`）
- 显示语言名称（如"英文"）
- 显示备份文件数量
- 提供备份文件查看功能

### 备份文件管理
- 点击"查看备份"查看所有备份文件
- 显示备份时间和文件大小
- 支持下载备份文件
- 按时间倒序排列

## ⚙️ 配置说明

### 语言文件映射
在 `server/translation-config.json` 中配置：

```json
{
  "apps": [
    {
      "appName": "myStar",
      "languages": [
        { "lanName": "英文", "lanFile": "en_US.json" },
        { "lanName": "日文", "lanFile": "ja_JP.json" },
        { "lanName": "中文", "lanFile": "zh_CN.json" }
      ]
    }
  ]
}
```

## 🔍 使用示例

### 上传英文翻译文件
1. 选择 `myStar` App
2. 选择"英文"语言
3. 上传文件 `translations.json`
4. 系统自动保存为 `en_US.json`
5. 如果有旧文件，自动备份

### 查看备份文件
1. 在文件列表中看到"备份文件: 3 个"
2. 点击"查看备份 (3)"
3. 查看所有备份文件列表
4. 可以下载任意备份文件

## ⚠️ 注意事项

1. **备份文件清理**: 建议定期清理旧备份文件
2. **存储空间**: 备份文件会占用额外存储空间
3. **文件名冲突**: 备份文件使用时间戳避免冲突
4. **权限管理**: 确保备份目录有写入权限
5. **配置更新**: 修改语言配置后需要重启服务器

## 🛠️ 维护建议

1. **定期清理**: 建议保留最近10个备份文件
2. **监控存储**: 定期检查备份目录大小
3. **配置备份**: 备份翻译配置文件
4. **日志监控**: 监控备份操作日志
