# 翻译修改功能说明

## 🎯 功能概述

翻译修改页面允许用户编辑和管理翻译内容，支持多语言翻译文件的批量编辑和保存。

## 📋 功能特性

### 1. App选择
- 从服务器配置动态加载App列表
- 选择App后自动加载对应的翻译数据
- 必须存在`source.json`文件才能进行编辑

### 2. 数据加载
- **source.json**: 源文文件，包含需要翻译的键值对
- **available.keys**: 可用键列表（可选），不在列表中的键会标红显示
- **翻译文件**: 各语言的翻译文件（如en_US.json、ja_JP.json等）

### 3. 表格编辑界面
- 三列布局：翻译键 | 源文值 | 翻译值
- 不在available.keys中的键会标红显示
- 支持多语言同时编辑
- 实时保存编辑内容

### 4. 文件备份
- 保存前自动备份原文件
- 备份文件以`_edit_`标记
- 支持恢复历史版本

## 🔧 技术实现

### 1. 前端实现

#### 数据结构
```dart
class TranslationItem {
  final String key;                    // 翻译键
  final String sourceValue;            // 源文值
  final Map<String, String> translations; // 各语言翻译
  final bool isInAvailableKeys;        // 是否在可用键列表中
}
```

#### 主要功能
- **App选择**: 动态加载App列表
- **数据加载**: 加载source.json、available.keys和各翻译文件
- **表格显示**: 三列布局显示翻译内容
- **编辑功能**: 支持多语言同时编辑
- **保存功能**: 批量保存所有翻译文件

### 2. 后端实现

#### 新增API端点
```javascript
// 备份翻译文件
POST /backup_translation
{
  "app": "myStar",
  "fileName": "en_US.json"
}

// 保存翻译文件
POST /save_translation
{
  "app": "myStar", 
  "fileName": "en_US.json",
  "data": { "key1": "value1", "key2": "value2" }
}
```

#### 文件处理逻辑
- 自动创建备份目录
- 备份文件命名：`原文件名_edit_时间戳.扩展名`
- 保存文件时格式化JSON（缩进2个空格）
- 错误处理和日志记录

## 📁 文件格式

### 1. source.json格式
```json
{
  "需要进行翻译的键": "翻译后的值",
  "welcome_message": "Welcome to our app",
  "login_button": "Login"
}
```

### 2. available.keys格式
```json
[
  "需要翻译的键1",
  "需要翻译的键2",
  "welcome_message",
  "login_button"
]
```

### 3. 翻译文件格式
```json
{
  "welcome_message": "欢迎使用我们的应用",
  "login_button": "登录"
}
```

## 🔄 工作流程

### 1. 数据加载流程
```
1. 用户选择App
2. 加载source.json（必需）
3. 加载available.keys（可选）
4. 加载所有翻译文件
5. 构建翻译项目列表
6. 显示编辑界面
```

### 2. 编辑保存流程
```
1. 用户编辑翻译内容
2. 点击保存按钮
3. 备份原文件（_edit_标记）
4. 保存新文件
5. 显示保存结果
```

## 🔍 使用指南

### 1. 准备工作
- 确保已上传source.json文件
- 可选上传available.keys文件
- 确保有翻译文件需要编辑

### 2. 编辑步骤
1. 选择要编辑的App
2. 等待数据加载完成
3. 在表格中编辑翻译内容
4. 点击保存按钮
5. 确认保存成功

### 3. 注意事项
- 不在available.keys中的键会标红显示
- 编辑内容会实时保存到内存
- 只有点击保存按钮才会写入文件
- 保存前会自动备份原文件
