# 服务器配置说明

## 📦 文件大小限制配置

### 当前配置
- **文件上传限制**: 600MB
- **JSON请求限制**: 5MB  
- **URL编码请求限制**: 5MB

### 配置文件位置
所有配置都在 `server/config.js` 文件中管理：

```javascript
limits: {
    fileSize: 600 * 1024 * 1024, // 600MB - 文件上传限制
    jsonLimit: '5mb',            // 5MB - JSON请求限制
    urlencodedLimit: '5mb'        // 5MB - URL编码请求限制
}
```

## 🔧 如何修改配置

### 修改文件大小限制

1. **编辑配置文件**:
   ```bash
   # 打开配置文件
   notepad server/config.js
   ```

2. **修改限制值**:
   ```javascript
   // 例如：设置为500MB
   fileSize: 500 * 1024 * 1024, // 500MB
   
   // 例如：设置为100MB
   fileSize: 100 * 1024 * 1024, // 100MB
   ```

3. **重启服务器**:
   ```bash
   # 停止当前服务器 (Ctrl+C)
   # 重新启动
   node server.js
   ```

### 修改API请求限制

```javascript
// 修改JSON和URL编码请求限制
jsonLimit: '10mb',        // 10MB
urlencodedLimit: '10mb'   // 10MB
```

## 📊 配置说明

### 文件上传限制 (fileSize)
- **用途**: 控制用户上传文件的最大大小
- **影响**: 超过限制会返回"PayloadTooLargeError"
- **建议**: 根据服务器存储空间和网络带宽设置

### JSON请求限制 (jsonLimit)
- **用途**: 控制API请求中JSON数据的大小
- **影响**: 笔记内容、API响应等
- **建议**: 5-10MB足够处理大部分API请求

### URL编码请求限制 (urlencodedLimit)
- **用途**: 控制表单数据的大小
- **影响**: 表单提交、查询参数等
- **建议**: 与JSON限制保持一致

## 🚨 注意事项

1. **重启生效**: 修改配置后必须重启服务器
2. **内存使用**: 大文件限制会增加服务器内存使用
3. **网络超时**: 大文件上传可能需要调整网络超时设置
4. **存储空间**: 确保服务器有足够的存储空间

## 📝 最佳实践

1. **生产环境**: 根据实际需求设置合理的文件大小限制
2. **安全考虑**: 不要设置过大的限制，防止恶意攻击
3. **监控使用**: 定期检查上传文件的大小和数量
4. **备份配置**: 保存配置文件到版本控制系统
