# 排除的频道列表（tv_name_hide.txt）
#
# 【格式】逗号分隔，换行与逗号等价：可以折成多行书写，行尾逗号可留可不留；
#        空行与空白项自动丢弃；LF / CRLF 均可；频道名本身含逗号时无法表达。
# 【注释】只有「行首是 #」的行会整行忽略（行中间的 # 会算进频道名）。
# 【匹配】两种写法（可混用）：
#        1) **精确全等**：`CETV-1`、`凤凰资讯` —— 名字一字不差才命中（大小写敏感，
#           空格要原样（半角/全角不同），例如「滁州市广播电视台 新闻综合」）。
#        2) **星号通配**（`*` 是唯一通配符，**忽略大小写**）：
#           `*咪咕*` 名字里含「咪咕」（会隐藏「咪咕赛事播40」）；
#           `咪咕*` 以「咪咕」开头；`*咪咕` 以「咪咕」结尾；`*a*b*` 先出现 a 再出现 b。
#        除 `*` 外的字符（含 `.` `+` `(` `[`）一律按字面处理，不会变正则；
#        整条只有 `*` 的模式（如误写一个 `*`）会被忽略，不会把整个列表隐藏。
# 【归一化】频道名与规则条目都会先做「CCTV/CETV 前缀补连字符」的归一化，
#        所以 `CCTV-1` 能隐藏接口给的 `CCTV1`，反过来写 `CCTV1` 也照样命中（`*CCTV1*` 同理）。
#        归一化只补前缀后的连字符，不动其余部分：`CCTV-4 欧洲`、`CCTV4K真4K` 各自独立。
# 【语义】命中的频道在「同名合并之后、排序之前」被整体剔除；重复写无副作用。
# 【生效】在 tv_name_order.txt 置顶排序之前执行。
# 【同步】从 GitHub 同步（启动时 + 「刷新频道」时）：git 最新 > 本地持久化缓存 >
#        包内 assets 默认值；线上改完要 App 下次启动 / 刷新频道才生效
#        （重新打包 APK 可立即带上）。
#
# 解析代码：lib/app/config/data_files.dart 的 parseList()
# 生效代码：lib/features/iptv/data/repositories/iptv_repository_impl.dart 的 _compose()
