# 服务器日志系统

## 📋 系统概述

服务器现在会在请求开始时立即打印日志信息，而不是等到请求完成后。这提供了更好的实时监控和调试能力。

## 🔧 日志功能

### 1. 全局请求日志中间件
```javascript
app.use((req, res, next) => {
    const timestamp = new Date().toISOString();
    const method = req.method;
    const url = req.url;
    const userAgent = req.get('User-Agent') || 'Unknown';
    const ip = req.ip || req.connection.remoteAddress || 'Unknown';
    
    console.log(`[${timestamp}] ${method} ${url} - ${ip} - ${userAgent}`);
    
    // 记录响应时间
    const startTime = Date.now();
    res.on('finish', () => {
        const duration = Date.now() - startTime;
        console.log(`[${timestamp}] ${method} ${url} - ${res.statusCode} - ${duration}ms`);
    });
    
    next();
});
```


## 🎯 日志内容

### 1. 请求信息
- **时间戳**: ISO格式的精确时间
- **HTTP方法**: GET, POST, DELETE等
- **请求路径**: 完整的URL路径
- **客户端IP**: 请求来源IP地址
- **用户代理**: 浏览器或客户端信息

### 2. 响应信息
- **状态码**: HTTP响应状态码
- **响应时间**: 请求处理耗时（毫秒）
- **处理结果**: 成功或错误信息

### 3. 业务信息
- **文件信息**: 文件名、大小、路径
- **操作类型**: 上传、下载、删除等
- **参数信息**: App名称、语言等
- **备份信息**: 文件备份操作

## ⚙️ 配置说明

### 日志级别
- **INFO**: 正常请求和响应
- **ERROR**: 错误和异常情况
- **DEBUG**: 详细的调试信息

### 时间格式
- **请求时间**: ISO 8601格式 (YYYY-MM-DDTHH:mm:ss.sssZ)
- **响应时间**: 毫秒级精度
- **持续时间**: 请求处理耗时

### 性能监控
- **响应时间**: 每个请求的处理时间
- **文件大小**: 上传文件的大小信息
- **操作类型**: 不同类型的操作耗时

## 🚀 优势

### 1. 实时监控
- 请求开始时立即显示日志
- 无需等待请求完成
- 实时了解服务器状态

### 2. 性能分析
- 精确的响应时间记录
- 不同操作的性能对比
- 瓶颈识别和优化

### 3. 错误调试
- 详细的错误信息
- 请求参数记录
- 错误发生时间点

### 4. 安全监控
- 客户端IP记录
- 用户代理信息
- 异常请求检测

## 📈 监控指标

### 关键指标
- **请求量**: 每分钟/小时请求数
- **响应时间**: 平均/最大响应时间
- **错误率**: 4xx/5xx错误比例
- **文件上传**: 上传成功率和文件大小

### 性能指标
- **处理时间**: 不同API的处理时间
- **文件操作**: 文件上传/下载性能
- **数据库操作**: 查询和更新性能
- **网络延迟**: 客户端到服务器延迟
