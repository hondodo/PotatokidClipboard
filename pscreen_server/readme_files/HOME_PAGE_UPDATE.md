# 主页功能更新说明

## 🎯 更新概述

在主页添加了翻译修改功能的入口，用户现在可以直接从主页访问翻译修改功能。

## 📋 新增功能

### 1. 翻译修改功能卡片
- **标题**: 翻译修改
- **描述**: 编辑和管理已上传的翻译内容
- **图标**: Icons.edit
- **颜色**: Colors.teal（青色）
- **路由**: /modify_translation

### 2. 功能卡片布局
```
┌─────────────────────────────────────────┐
│ 📤 上传文件                             │
│ 选择并上传文件到服务器                   │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 📁 文件管理                             │
│ 查看、管理和删除已上传的文件             │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 📝 笔记管理                             │
│ 创建、查看和管理个人笔记                 │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ 🌐 翻译上传                             │
│ 上传和管理App翻译文件                    │
└─────────────────────────────────────────┘

┌─────────────────────────────────────────┐
│ ✏️ 翻译修改                             │
│ 编辑和管理已上传的翻译内容               │
└─────────────────────────────────────────┘
```

## 🔧 技术实现

### 1. 功能卡片添加
```dart
_buildFeatureCard(
  context: context,
  title: '翻译修改',
  description: '编辑和管理已上传的翻译内容',
  icon: Icons.edit,
  color: Colors.teal,
  route: '/modify_translation',
),
```

### 2. 路由配置
```dart
routes: {
  '/': (context) => const HomePage(),
  '/upload': (context) => const UploadPage(),
  '/files': (context) => const ViewUploadPage(),
  '/notes': (context) => const NotePage(),
  '/upload_translation': (context) => const UploadTranslationPage(),
  '/modify_translation': (context) => const ModifyTranslationPage(),
},
```

### 3. 使用说明更新
```
1. 点击"上传文件"按钮可以上传新文件到服务器（最大300MB）
2. 点击"文件管理"按钮可以查看和管理已上传的文件
3. 点击"笔记管理"按钮可以创建和管理个人笔记
4. 点击"翻译上传"按钮可以上传App翻译文件（.json格式）
5. 点击"翻译修改"按钮可以编辑和管理已上传的翻译内容
6. 支持多种文件格式：文档、图片、视频、音频等
7. 笔记按用户名分类，只有输入正确用户名才能查看
```
