# 时间显示系统

## 📋 系统概述

所有页面的时间显示已从标准时（UTC）转换为当地时间显示，提供更好的用户体验。

## 🔧 时间格式化功能

### 1. 标准时间格式
- **格式**: `yyyy-MM-dd HH:mm:ss`
- **示例**: `2024-01-15 14:30:45`
- **用途**: 详细时间显示，如备份文件时间

### 2. 简短时间格式
- **今天**: `今天 HH:mm:ss`
- **昨天**: `昨天 HH:mm:ss`
- **本周**: `星期X HH:mm`
- **其他**: `MM-dd HH:mm`
- **用途**: 列表显示，节省空间

### 3. 相对时间格式
- **刚刚**: 1分钟内
- **X分钟前**: 1小时内
- **X小时前**: 24小时内
- **X天前**: 7天内
- **MM-dd**: 7天以上
- **用途**: 社交化显示

## 📱 应用页面

### 翻译上传页面
- **备份文件时间**: 使用标准时间格式
- **显示位置**: 备份文件列表中的"备份时间"字段

### 文件管理页面
- **上传时间**: 使用标准时间格式
- **显示位置**: 文件列表中的"上传时间"字段

### 笔记管理页面
- **创建时间**: 使用标准时间格式
- **显示位置**: 笔记列表中的"创建时间"字段

## 🛠️ 技术实现

### 时间工具类
```dart
class TimeUtils {
  // 标准时间格式
  static String formatLocalTime(String? isoTime)
  
  // 简短时间格式
  static String formatLocalTimeShort(String? isoTime)
  
  // 相对时间格式
  static String formatRelativeTime(String? isoTime)
}
```

### 使用示例
```dart
// 标准时间格式
TimeUtils.formatLocalTime('2024-01-15T10:30:45.123Z')
// 输出: 2024-01-15 18:30:45

// 简短时间格式
TimeUtils.formatLocalTimeShort('2024-01-15T10:30:45.123Z')
// 输出: 今天 18:30:45

// 相对时间格式
TimeUtils.formatRelativeTime('2024-01-15T10:30:45.123Z')
// 输出: 2小时前
```

## 🌍 时区处理

### 自动时区转换
- 服务器返回UTC时间
- 前端自动转换为用户本地时区
- 支持全球不同时区用户

### 时区示例
```
UTC时间: 2024-01-15T10:30:45.123Z
北京时间: 2024-01-15 18:30:45 (UTC+8)
纽约时间: 2024-01-15 05:30:45 (UTC-5)
伦敦时间: 2024-01-15 10:30:45 (UTC+0)
```

## ⚠️ 注意事项

1. **时区一致性**: 确保服务器和客户端时区设置正确
2. **性能考虑**: 时间格式化有轻微性能开销
3. **错误处理**: 时间解析失败时显示友好错误信息
4. **格式统一**: 所有页面使用统一的时间格式
