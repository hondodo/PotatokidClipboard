设备状态

设备通过 Android ID 自动注册；在线判定为 90 秒内收到心跳。家庭权限优先级：机器设置 > 所属用户设置 > App 的 .env。

名称显示优先级：客户端本机备注别名 > 账号展示名（displayName） > 设备备注（设备名） > 账号 id。本机备注只存在于设备本地，后台不可见；空值统一标为「未设置」。

设备判定规则

定义「哪台设备算空调 / 热水器 / 电视」。规则之间 OR、规则内条件之间 AND；多条命中时按具体度优先、再按优先级裁决。判定结果返回给 home，由 home 按类型选用各自不同的专用卡片。

字段/操作符为开放输入 + 推荐候选：attr.属性名 取任意 HA 属性，device.model 取设备型号（如 xiaomi.tv.v1，比实体 ID 前缀稳定）；「开头是」自动忽略 button. / switch. 域前缀。保存后服务端即时生效。

ESP 设备分类

一页 = 一台被控设备。每页有自己的页面名、屏幕显示内容和一组按键；设备上按「下一页」整页切换，不用为每种设备重做固件。

屏幕显示内容在每页模板里直接写实体 id（如 {switch.bedroom}），填什么显示什么、无兜底；按键槽位 1~8 只是逻辑编号，物理 GPIO 在设备本地设置页分配，换接线不用改这里。
