设备判定规则

定义「哪台设备算空调 / 热水器 / 电视」。规则之间 OR、规则内条件之间 AND；多条命中时按具体度优先、再按优先级裁决。判定在服务端统一算，home 端按结果显示卡片、ESP 端哑巴显示四行文本。

字段/操作符为开放输入 + 推荐候选：attr.属性名 取任意 HA 属性，device.model 取设备型号（如 xiaomi.tv.v1，比实体 ID 前缀稳定）；「开头是」自动忽略 button. / switch. 域前缀。保存后写回字典覆盖层，两端即时生效。
