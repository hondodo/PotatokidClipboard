## 摄像机跨型号匹配修正（18:55）
- 用户反馈：去掉 `cw501d_` 前缀改短后缀后仍有两台匹配不到。根因**不是前缀**（前缀是型号标识、不会变），而是三台摄像机字段名不同：
  - cw501d(4双摄版)：补光灯 `s_21_white_light`(light)、接入方式 `access_mode_p_29_5`
  - cw500/hlmax(CW500系列)：**无上述字段**，补光灯是 `hl_filllight_switch_p_6_16`(switch)、**无接入方式字段**
  - 三台共有 `on_p_2_1` / `status_p_4_1`
- 关键发现：**`fallback=` 可跨型号顺延，显示值和动作 id 都支持**（`{id:a|fallback=id:b}` 渲染时 resolve 成真实 entityId）。但 `fallback` 后接内联映射（on=/off=/default=）会被 default 抢先兜底而失效——**正确写法是 fallback 只取值，映射放节点级 `map` 字段**。
- 最终 JSON 写法：`label: "{s:_s_21_white_light|fallback=s:_hl_filllight_switch_p_6_16}"` + `map: "on=补光灯 开,off=补光灯 关,default=补光灯"`；`onClick: "toggle@{id:_s_21_white_light|fallback=id:_hl_filllight_switch_p_6_16}"`。网络行因另两台无接入方式字段，用 `blank=网络正常,default=网络正常` 兜底。
- 加了 3+3 条测试（fallback 显示/id + 三台真实数据模拟），`card_layout_test.dart` **73/73 通过**。纯 JSON，无 Dart/服务端改动。
