ESP 设备 6

设备分类配置

1设备类型 在此显式声明，不靠猜

类型选一次。规则定义在 （全局 Tab），这里只引用类型、绑定实体。未选类型走通用兜底。

2实体绑定 从 HA 实体库下拉选，不手填后缀

按类型不同要绑的字段不同（热水器要「当前水温/工作状态」，洗衣机要「剩余时间/运行模式」）。绑定存进 deviceType + displayBindings。

3按键定义 支持带数值/模式的动作

槽位短标签行为（含参数）
「温度 +/−」= 同一个 set_temperature 带不同数值，非新动作种类。参数由服务端按当前值 ± 步长算出。

4命中的字典规则 定义在全局字典 Tab

规划原型 · 仅演示信息架构与交互，未接真实接口。设备取自线上 datas/admin/machines.json 的真实形态，实体库为模拟数据。
信息架构：「设备类型字典」= 全局规则（唯一真源，home + ESP 共用）；「ESP 设备分类」= 每台设备选类型 + 绑实体 + 按键，两者都是 Admin 顶层 Tab、可互相跳转。
屏幕渲染遵循既定约定：单色三选一、无虚线、反白强调异常、跑马灯仅在放不下时触发、顶部状态栏含页码/IP/WiFi（IP 落地取 WiFi.localIP()）。
