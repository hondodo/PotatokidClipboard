ESP 屏幕配置

设备状态 / esp32s3-3030f96cd03c / 屏幕配置
核心概念：以「页面（Page）」为单位配置。 一页 = 一个设备 + 一份屏幕显示内容 + 一组按键定义。按「下一页」后，按键含义和屏幕内容整页切换 —— 不用为每种设备重做固件。 右侧预览按真实 128×64 像素渲染（3× 放大），改任何配置都会实时更新。 联网状态固定在屏幕顶部，不受页面配置影响。 任何一行文字显示不下时才会跑马灯循环滚动（不截断、不加省略号）——短文字照常静止，不会满屏乱跑；打开右侧「超长文本演示」可看极端情况。即使几行同时超长也不同步：标题最慢、按键提示最快。实物屏幕有蓝光 / 白光 / 黄光三种单色版本，右侧可切换预览。

页面配置

① 页面属性

页面名称
图标
名称显示在屏幕顶部状态栏下方；图标用于后台列表，不占屏幕像素。

② 屏幕显示内容 用户真正关心的信息

位置HA 实体 / 数据来源显示格式
受 128×64 限制：标题 1 行 + 主状态 1 行 + 副状态 1 行 + 底部按键提示 1 行。 第 2 行起会拼成一行（如 42°C · 目标 45°C）。主状态推荐放开关状态 / 当前温度 / 当前档位。

③ 按键定义 按页面切换，含义跟着变

槽位短标签（显示在屏幕底部）行为
「行为」可选 HA 动作（开/关/切换/执行/数值+/-）或 系统动作（下一页 / 上一页 / 回首页）。 同一物理按键在不同页面可绑定完全不同的行为。
屏幕底部提示条只有 128px、5 个按键摆一行 → 短标签最多 2 字（推荐 1 字）。 完整的控制项名称仍保留在后台和按键反馈提示里，不受此限制。

④ 翻页与安全

循环翻页
空闲返回
翻页不需要新增硬件按键 —— 把任意槽位的行为设为「下一页」即可。

跑马灯速度：标题 0.45× · 主状态 0.75× · 副状态 1.1× · 按键提示 1.6×（各行独立、不同步）
落地说明：配置存服务端 machines.json 的 espPages（每页含 display + buttons）； 设备心跳时通过 GET /api/device/esp/actions 拉到「当前页的按钮定义」，通过 GET /api/device/esp/screen 拉到「当前页的显示内容」。 服务端负责把 HA 实体状态翻译成屏幕文本（如 on → 开、42.5 → 42°C）， ESP 只按文本渲染，不需要 JSON 解析库和中文字库之外的逻辑。WiFi / 服务端状态由固件直接画在顶部，不参与页面配置。
