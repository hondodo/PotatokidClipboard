每路一个大按钮（repeat 节点）

多路开关不再显示「已开启路数」统计和总电源按钮 —— 每路就是一个独立 switch 实体， 直接渲染成一个大按钮：按钮文字 = 路名，点亮态 = 该路 state，点击 = 切换该路。路数由 {gangs} 自动推断， repeat 节点按列表长度循环生成 N 个按钮，双开 / 四开是同一份 JSON。

效果：双开（2 个大按钮）

效果：四开（4 个大按钮，同一 JSON）

协议示例

{ "type": "repeat", "source": "{gangs}", "item": "gang",
  "gap": 8, "columns": 2,
  "template": {
    "type": "button",
    "label": "{gang.label}",
    "subLabel": "{gang.isOn ? '已开启 · 点击关闭' : '已关闭 · 点击开启'}",
    "style": "{gang.isOn ? 'active' : 'normal'}",
    "onClick": "toggle({gang.entityId})"
  }
}
要点：{gangs} 从组内 switch 实体实时求值（含 label / isOn / entityId）， columns 控制每行几个按钮（双开 2 列、四开 2 列两行、八开可用 3 列）。 onClick 带每路自己的 entityId，仍走 toggle 白名单 —— 动态布局，但交互安全不变。

支持的节点类型（一期）

节点关键属性说明
row / column / wrapgap, crossAlign, expand, padding布局容器，可任意嵌套；wrap 自动换行
repeatsource, item, columns, gap, template按列表（如 {gangs}）循环生成节点；每路一个大按钮即用它
textvalue, size, weight, color, maxLines, overflow文本，value 支持 {占位符} 绑定
iconvalue, size, box{size,radius,bg,color}图标，来自 card.icon 或 Material 图标名
buttonicon/label, onClick, visibleWhen, loading动作按钮，白名单派发
chiplabel, onClick, style(outlined/filled)小按钮，用于多动作组
progressvalue, max, color, height进度条（亮度/音量/电量）
sparklinemetric, window, showLabels, color, height实时趋势曲线（功率/温度/湿度），接现有 MetricSparkline
dividercolor, thickness分隔线

颗粒度边界

能做到：任意行列嵌套布局、间距对齐权重、字号颜色圆角、数据绑定与模板拼接、条件显隐、进度条、按钮动作 + 二次确认、主题色联动。新增一种卡片 = 后台配一份 JSON，不用改 Dart、不用发版装机。

图表可做：实时功率/温度/湿度曲线通过 sparkline 节点接入项目已有的 PowerStats + HistoryService + MetricSparkline 链路（插座卡片已在用），非重造，配 2×1 / 2×2 大卡片展示。

刻意不做：任意 JS/脚本执行（安全）、高度定制的复杂可视化（多轴/饼图/甘特）、跨卡片联动、手势拖拽——这些留给少数编译期专用 Widget 兜底（现有 13 个 Summary 即是此角色）。
